Bookmark Desk — explicit local pairing

  1. Start the actual Tauri desktop app (not the Vite browser preview).
  2. Open Browser extension in desktop and pair this extension ID:
  3. Build the debug connector and run the per-user registration script shown in the desktop setup instructions. Register Chrome, Edge, or both. No administrator access is needed.
  4. Enable below and test the connection. Leave desktop running for saves and retries.

No bookmark history permission or automatic browser bookmark sync. Current page title, URL and favicon address are captured locally. No third-party favicon service is used. Right-click saves use the last defaults selected in the popup.

Pending saves

Queue remains in this browser profile until confirmed. A rejected save stays visible and needs attention. Remove and save again to change invalid metadata or deleted collections. Uninstalling the extension clears its queue.
